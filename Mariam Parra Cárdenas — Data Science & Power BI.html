fact_sales (OrderID, DateKey, CustomerID, ProductKey, Quantity, UnitPrice, Discount, Revenue, Cost) → dim_date · dim_product · dim_customer. One-to-many relationships; dim_date marked as date table.

Total Revenue = SUM ( fact_sales[Revenue] )
Total Cost = SUM ( fact_sales[Cost] )
Gross Margin % = DIVIDE ( [Total Revenue] - [Total Cost], [Total Revenue] )
Orders = DISTINCTCOUNT ( fact_sales[OrderID] )
Avg Order Value = DIVIDE ( [Total Revenue], [Orders] )
Revenue PY = CALCULATE ( [Total Revenue], SAMEPERIODLASTYEAR ( dim_date[Date] ) )
Revenue YoY % = DIVIDE ( [Total Revenue] - [Revenue PY], [Revenue PY] )
Revenue YTD = TOTALYTD ( [Total Revenue], dim_date[Date] )
Revenue 3M Avg = DIVIDE ( CALCULATE ( [Total Revenue], DATESINPERIOD ( dim_date[Date], MAX ( dim_date[Date] ), -3, MONTH ) ), 3 )
